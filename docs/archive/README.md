# Documentation archive

This directory preserves historical project material that is useful for traceability but is not a source of truth for the current build.

- `releases/` — historical release notes.
- `qa/` — historical version-specific QA reports.
- `recovery/` — one-off patch/recovery instructions, old readmes and checksum manifests.
- `stages/` — stage-specific implementation/QA notes such as the original pie-chart work.
- `reference/` — superseded planning/reference snapshots retained for context.

For current maintainership guidance, start at [`../README.md`](../README.md).

If an archived document disagrees with current code or current documentation, the archived document is historical and must not be used to overwrite current behaviour without a fresh investigation.
