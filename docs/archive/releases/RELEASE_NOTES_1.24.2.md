# 99 Club Studio v1.24.2 — printer-friendly Crossword house style

- Replaces newspaper-style blocked Crossword rendering with a freeform classroom criss-cross.
- Browser preview draws only active answer cells; unused positions remain white page.
- Direct PDF renderer draws only outlined answer cells, with no solid black blocks or enclosing square.
- Crossword data is trimmed to the exact occupied footprint so puzzles scale larger and waste less space.
- Answer PDFs use the identical footprint with letters filled in.
- Existing pupil / answer / combined PDF download choices remain unchanged.
