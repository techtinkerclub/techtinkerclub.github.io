# 99 Club Studio v1.31.0

Arithmetic & Calculation expansion inspired by printable maths-crossword / number-search formats.

- extends Maths Crossnumber with arithmetic, equation and mixed clue modes;
- adds Number Search with calculation-led hidden numerical answers;
- guarantees intended Number Search answers are not duplicated accidentally in the filler grid;
- adds Arithmetic Equation Crossgrid with interlocking across/down equations;
- adds browser preview, answer view, PDF output and worked examples for both new engines;
- expands the Games library from 23 to 25 engines;
- preserves all v1.30.6 Number Patterns/PDF corrections.
