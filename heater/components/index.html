Component identification

The reference list covers the incoming mains equipment, controllers, relays, SSRs, buttons, lamps, protection, all specified distribution blocks and panel connectors. The model is the intended rebuild specification; inspect actual markings when replacing an installed part.

All specified panel connector and meter models are now identified from the two-channel BOM audit: Murata DMR20-10-DCM-R-C (2), Electro PJP 3266-I-R/3266-I-N (4 of each), and RS PRO Type K 455-9742 (2). Meter fusing: Murata requires 0.25 A / 300 V time-delay external fusing of meter supply wiring; the original R1 drawings omit these branches. The correct DC fault-interruption and fuseholder selection still needs to be included in a revised issue.
