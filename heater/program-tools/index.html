Programme

Rate-of-rise method
This is a planning choice, not a controller connection. The physical probe, current C3 configuration and setpoint limits must be verified independently. Only rate-of-rise mode is implemented in v1 (t-pr = pr, pru = m, t-u = h-m). The separate step-time programming method requires a different parameter model. The starting PV is assumed for the graph and cannot be forced by a leading ramp.

Segments

2 / 32

Ramp = SP + whole-number slope (profile units/min). Soak = hold existing SP for a duration. Step = immediate setpoint jump (zero programmed time). To wait for the actual temperature before the next segment, verify controller-wide wt-b is enabled in Adjustment Level. It affects all segments/programmes; this website cannot change it.

Operation · RESET

Virtual programme values are automatically kept in this browser, even after page reload. The Power-cycle button resets the virtual operating state (for p-on = rst) while retaining programme memory and prg. This models our observed USB restart test, not any real controller output. LEVEL moves Operation → Programme → Adjustment → PID → Operation. Hold LEVEL from Operation to enter Initial Settings and from Initial Settings to return. MODE scrolls displayed parameters, or previous parameter when held. Some real parameters are omitted, so never learn a fixed number of MODE presses from this simulator.

Run the virtual programme

0 min

Virtual only: from r-r = rst, press DOWN to request RUN; UP leaves RESET unchanged. Virtual time advances with +1/+5 min buttons; PV remains at its assumed starting temperature. The RST lamp is virtual; OUT1/OUT2 are deliberately not simulated. The indicators are not measurements of heater current.

Practice target

Use LEVEL, MODE and UP/DOWN to enter the displayed programme. At d.seg, choose a numbered segment; at d.seg = end, review programme-wide settings. This is a simplified Type K training interface.

Load is a shortcut to populate virtual memory for practice; it does not represent physically programming the device. To practise accurately, instead enter every value with LEVEL, MODE, UP/DOWN and PF, then select prg in Operation Level. Follow the step-by-step procedure ↗

Stuck on a menu? Use the interactive MODE map of Programme Setting Level to see every documented segment and programme-wide parameter, or browse all sensor input selections. The atlas is not a live controller.

How to create, save and select a programme

  1. Set t-pr = pr, pru = m, t-u = h-m, p-on = rst, eset = rst in Initial Level, and spmd = psp in Adjustment Level.
  2. From Operation, short LEVEL → d.prg: choose an editing slot. MODE → s-no → d.seg; for each ramp enter styp, sp, pr; for a soak enter styp, time.
  3. After the final segment, MODE advances to d.seg = end. Check programme-wide pid, rpt = 0, link = end. There is no separate physical Save key: confirm the stored values by returning to the menu and power-cycling.
  4. Return to Operation. At prg select the programme to run; check pgsg and r-r = rst. The RUN programme can differ from the d.prg editing slot.
Operation Level includes prg (RUN memory), pgsg (programme/segment) and r-r (RUN/RESET). Explore the full MODE sequence →

Simulator scope

The virtual keypad supports programme-entry practice and simplified +1/+5 min timing. It does not simulate real outputs, alarms, autotuning or every firmware-specific menu. For the full menu tree see the Omron atlas; for controller bench observations see the engineering record.
