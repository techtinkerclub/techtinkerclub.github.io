Pre-commissioning training software, not a real controller. These graphs show the commanded setpoint, not measured PV or heater behaviour. This simulator intentionally models only the documented common settings; protection, alarms, PID, wait/hold, and several special functions are not reproduced. Check actual controller screens and complete the independent electrical safety commissioning before live use.

Rate-of-rise method
Only rate-of-rise mode is implemented in v1 (t-pr = pr, pru = m, t-u = h-m). The separate step-time programming method requires a different parameter model. The starting PV is assumed for the graph and cannot be forced by a leading ramp.

Operation · RESET

LEVEL moves Operation → Programme → Adjustment → PID → Operation. Hold LEVEL from Operation to enter Initial Settings and from Initial Settings to return. MODE scrolls displayed parameters, or previous parameter when held. Some real parameters are omitted, so never learn a fixed number of MODE presses from this simulator.

Practice target

Match each plain-English setting to the exact code on the Omron screen. Select a segment with d.seg before editing styp, sp, pr or time. MODE after the final segment parameter returns to d.seg = end (verified for one active segment). On the tested real controller, programme 0 shows al-1 = al-2 = al-3 = 0; the simulator mirrors these read-only values for slot 0. Other slots remain unverified (--). This does not mean alarms are disabled. PID Setting Level now follows the observed d.pid → 1.p → 1.i → 1.d → 1.olh → 1.oll → 1.aut → d.pid loop when PID set 1 is selected. These PID-1 values are a read-only example copied from one real controller; PID editing, other PID sets and masked parameters are not simulated.

Load is an explicit shortcut for exploring a completed programme; it does not represent physically programming the device.

Known limitations

This first simulator covers a restricted parameter subset, approximate PF numeric digit editing, mode navigation, segment editing and virtual setpoint progression. It does not exactly model firmware-specific parameter masking, alarms, autotuning, programme linking/repeats, wait/hold, protected levels or control outputs. Training accuracy must be checked against both installed E5CC-TQX3A5M-000 controllers.
