Select a level to trace its complete MODE-ordered parameter path. The diagram describes navigation, not live electrical state. Factory calibration is an intentionally excluded specialist path. Protect/masking and firmware can hide parameters and change which keys are available.

Printed source: H185-E1-08 Appendix A-9. Parameter visibility depends on firmware, protection and hardware.

Reference provenance: Omron H185-E1-08, A-9 Parameter Flow (printed A-38–A-40), A-6 Parameter Operation Lists (A-18–A-33), and H186 communications reference. The E5CC-T model filter is a documentary interpretation of nameplate option codes; it cannot identify a connected controller or prove an option is physically fitted.
