This procedure describes the intended two-channel R1.2 reference circuit. Each channel uses an Omron E5CC-T, Schneider CONTROL selector, Finder 13.61 RI enable relay, Finder 62.31 DC contactor relay, Weidmüller interface, Crydom DC SSR, EAO momentary ENABLE switch and an amber ACTIVE indicator.

Conditions before live operation: independent electrical review/inspection, rated DC isolation and protection, PE continuity, SSR thermal and relay/socket current verification, tested RESET output-off behaviour, safe power restoration and the site-specific experiment risk assessment. A working demonstration does not establish these as completed.
Controller / programmeNot hardwired to the EAO button. r-r = rst and r-r = run must be changed on the Omron itself.
Heater enableEAO is a momentary toggle (Finder RI): ON/OFF. It is not an emergency stop or rated isolator.
Two independent DC sourcesEach channel's separate external supply may deliver up to 60 V DC / 15 A. Limits depend on the approved test.
Recommended start order: fit/connect with all sources isolated → mains controls ON and programme checked in RESET → set external PSU limits with output OFF → turn DC output ON with heater disabled → enable channel (confirm no demand) → set Omron RUN → monitor. This sequence is conditional on a verified rtsm = stop / mv-r = 0.0% output-off state.

A · Prepare the experiment

No electrical power applied to the heater circuit

6 steps
01

Check permission and test plan

Have a test ID, authorised specimen/fixture, maximum temperature, heating rate, duration, cooling arrangement and sample-specific risk controls.

Expected / checkApproved test plan; assigned operator and observer where required.
If not correctDo not proceed without a suitable test-specific risk assessment.
02

Make the area safe

Check enclosure, ventilation, access restrictions, guards, hot-zone exclusion, monitoring, independent cut-off and emergency arrangements. Identify the DC supply's accessible OFF/isolation control.

Expected / checkNo exposed hot or live parts in the work area; appropriate protection in place.
If not correctThe EAO ENABLE button is not a safety-rated emergency stop.
03

Inspect controller and cables

Check mains cable, door/earth strap, 24 V controls, banana leads and connectors for damage, looseness, scorching and correct current ratings.

Expected / checkNo defects; enclosure closed for operation.
If not correctNever open the mains/DC enclosure while energised.
04

Fit and secure the heater and specimen

Secure the heater in its approved fixture, maintain specified contact, insulation, ventilation and separation from combustibles; place additional independent over-temperature sensing if required.

Expected / checkHeater stable; leads strain-relieved; no accessible heated surfaces.
If not correctUse the specimen's dedicated hazard controls; do not assume all specimens are inert.
05

Connect the Type K thermocouple

With power isolated, connect to the matching green JTC input. Confirm it measures the intended heated location, is securely mounted and is correctly polarised.

Expected / checkCorrect channel, correct sensor position and intact thermocouple cable.
If not correctA plausible controller reading later is essential; a missing sensor may show s.err.
06

Connect external DC cables — still de-energised

Confirm external PSU OUTPUT OFF and isolated. Connect positive/negative from PSU to the matching upper PSU IN pair. Connect heater to the lower HEATER OUT pair on the same channel. Check red/black polarity and conductor/connector current rating.

Expected / checkExternal DC source and heater both match the channel; leads firmly seated.
If not correctDo not plug, unplug or move banana leads with the external PSU energised.

B · Power controls and load the programme

External heater DC output remains OFF

7 steps
07

Set initial safe positions

External DC PSU OUTPUT OFF; Omron CONTROL selectors OFF; no channel enabled. Decide which channel will be used; use one channel first unless simultaneous operation is specifically approved.

Expected / checkEAO ENABLE LED OFF; amber ACTIVE OFF when its positive is on Finder 13.61 terminal 14, as reported. Check both channels individually.
If not correctIf ACTIVE flashes with ENABLE OFF, stop and check the indicator wiring. Do not assume the other channel has also been modified.
08

Turn on enclosure mains

Apply mains through the installed inlet switch using the site's approved energising procedure. The shared 24 V supply should start.

Expected / checkNo smell, buzzing, damaged insulation or unexpected electrical activity.
If not correctA healthy PSU indication is useful but does not replace electrical tests.
09

Switch on the selected Omron channel

Turn the channel's maintained CONTROL selector ON and observe the Omron boot to its temperature screen.

Expected / checkOmron PV displayed; other channel independently controlled; no error indication.
If not correctIf controller will not power or reports errors, keep external DC OFF.
10

Confirm the sensor reading

Compare PV with independently known ambient/process temperature; check sensor type and units match the fitted Type K. Move no leads while powered.

Expected / checkPV reasonable, stable; no s.err, e111 or e333.
If not correctStop for any implausible PV, loss of sensor, unexplained fault or incorrect input configuration.
11

Select and check the programme

From normal screen use MODE briefly to reach r-r and confirm rst. Continue MODE to prg and select the approved programme slot; return/read back prg and pgsg. Review target, ramp, soak, repetition, end and limits against the test plan.

Expected / checkr-r = rst; prg = correct programme; pgsg shows the intended programme/segment.
If not correctd.prg selects a programme for editing; prg selects it for RUN.
12

Confirm the controller's safe RESET behaviour

Before enabling DC, confirm the approved configuration rtsm = stop, p-on = rst, mv-r = 0.0%; with r-r = rst, check the SSR demand output is actually inactive on this installed system.

Expected / checkRUN not active; no controller demand and no ACTIVE indication if LED is enable-gated.
If not correctDo not use the preferred start sequence unless the RESET/output-off behaviour has been electrically verified. In RESET alone, the relay is not isolated.
13

Set external PSU limits with output OFF

Set and record the authorised DC voltage ceiling and current limit using the PSU manufacturer's instructions. External supply must support the required current and have appropriate independent protective/isolation devices.

Expected / checkRecorded V limit and I limit, no load output applied.
If not correctDesign envelope up to 60 V DC / 15 A per channel is a maximum, not the default test setting.

C · Apply DC power and begin heating

One deliberate action per subsystem; no automatic link between EAO and Omron RUN

5 steps
14

Energise the external PSU under supervision

With controls checked and heater ENABLE still OFF, turn on external supply/output using the approved supply operating method.

Expected / checkMurata DC VOLTS displays input voltage when above its minimum operating threshold (about 6 V); ENABLE remains OFF; no heater output expected.
If not correctThe meter measures the external supply input, not confirmation of heater voltage/current or safe isolation. If any heating occurs, isolate the supply.
15

Enable the channel

Press and release the momentary EAO ENABLE button once; do not hold it. Confirm the enable state using the button's ring LED and Finder 13.61 indication.

Expected / checkEAO ring ON; Finder 13.61 ON indication; Finder 62.31 relay enabled. With r-r = rst and no demand, amber ACTIVE remains OFF on the R1 wiring.
If not correctIf the EAO ring state or relays disagree, or the ACTIVE lamp shows demand in RESET, isolate external DC and investigate.
16

Start the selected Omron programme

At the Omron operation level, press MODE briefly until r-r. Set rst → run using the appropriate UP/DOWN key, then press MODE to confirm. Use the controller's exact displayed codes; do not use an unverified keyboard shortcut.

Expected / checkr-r = run; prg remains the approved programme; pgsg and prgt advance as expected.
If not correctHeating begins only when enabled AND commanded by Omron. Watch for unexpected immediate full output or wrong setpoint.
17

Observe the first heating response

Check PV vs SP, actual independent process temperature where provided, heat response, noise, odour, current/voltage readings on the EXTERNAL supply and the amber ACTIVE LED.

Expected / checkACTIVE can pulse with demand; temperature rise consistent with the test; no unexpected trips or alarms.
If not correctACTIVE shows commanded SSR input, not actual heater current. If the bulb still uses selector-gated +24 V, its behaviour differs when disabled.
18

Monitor throughout the test

Remain within the approved supervision arrangement; log PV/SP, programme/segment/time, external PSU settings/current, independent temperature and anomalies at the agreed intervals.

Expected / checkCorrect segment progression and heat rate; protective limits not approached.
If not correctNever leave an unapproved heating test unattended; no touching or reconnecting energised leads.

D · Stop, cool and isolate

Normal shutdown versus urgent stop

5 steps
19

Complete the normal programmed test

On completion, confirm the intended Omron end behaviour and actual heating demand; do not infer heater-off from a timer alone.

Expected / checkProgram ends as configured; process stable.
If not correctSome Omron end settings can continue at a final SP; verify rather than assuming OFF.
20

Command Omron RESET

Use MODE to r-r and set rst. Confirm the commanded heating output ceases under the verified RESET configuration.

Expected / checkr-r = rst; demand/ACTIVE OFF after output stops.
If not correctIf the control fails, bypass this step and use the external PSU's approved isolation method.
21

Disable the ENABLE circuit

Press the momentary EAO button once to turn its ring OFF; verify Finder enables drop and no heater output remains.

Expected / checkEAO ring OFF; Finder enable OFF; amber ACTIVE OFF on the R1 gated circuit.
If not correctThe EAO is an operating command, not a safety-rated emergency disconnect.
22

Turn the external DC supply OFF and isolate

Switch external PSU OUTPUT OFF, then isolate it using the approved disconnect; verify output has been de-energised by a suitable method. Keep the heater connections undisturbed until safe.

Expected / checkExternal supply OFF and isolated; meter may go blank below approx. 6 V but darkness alone does NOT prove zero voltage.
If not correctExternal PSU stored energy may persist; verify before unplugging connectors.
23

Allow cooling; complete records

Continue safe temperature monitoring until heater, fixture and specimen reach the authorised handling temperature; then switch controller mains/CONTROL OFF as appropriate. Record final PV, run ID, profile, voltage/current, trips, deviations and observations.

Expected / checkDocumented end of test; area left safe; relevant cooling and post-test observations recorded.
If not correctDo not handle a hot or potentially reactive sample just because heating power is removed.

The separate programme RUN/RESET and heater ENABLE functions are intentional on the present controllers. Disabling the heater while RUN remains active will not pause the Omron programme. For an interrupted test, isolate the external DC source and treat the run as aborted; command RESET before a new test.

Fault response and emergency actions

Emergency response must match the site test-cell/emergency procedures and specimen-specific assessment. The safe upstream DC disconnect, fire response and evacuation routes must be identified before the test.

Unexpected heating / controls not stopping

Use the approved external DC emergency isolation or upstream disconnect immediately if safe to do so. Do not rely solely on Omron RESET or the EAO enable button. Warn others, keep clear and follow local emergency response.

Sensor fault (s.err), Omron memory/converter error (e111/e333), wrong PV

Isolate external heater power. Do not bypass the thermocouple; verify cable, connector, sensor type and controller condition before restarting.

Smoke, fire, venting, explosion, hot-cell reaction

Raise the alarm, evacuate/exclude personnel and follow the facility's approved sample-specific emergency plan; do not attempt close intervention or assume power removal halts a reaction.

Power interruption/restoration

Treat the run as aborted. Isolate DC output; check the Omron remains in RESET, Finder ENABLE OFF and demand inactive before beginning an entirely new test.

Wrong channel, unexpectedly lit ACTIVE LED, or indicators disagree

Stop, isolate both external sources as applicable, and trace cable/indicator wiring against R1. Do not interpret an LED alone as proof of current or electrical isolation.

Do not open the controller cabinet or disconnect energised banana leads to diagnose a fault. A dark LED or Murata display alone does not establish safe isolation; verify de-energisation with suitable test equipment and isolation procedures.
