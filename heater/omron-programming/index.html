Five controller keys — exactly as on the front panel

The physical buttons are not marked O, M or S. Those are abbreviations used in Omron's technical documentation. Read the symbols below from left to right, matching the real controller. Use the named key in the instructions, not a letter that you expect to see printed on the panel.

1 · LEVEL

Leftmost key. Move between setting levels. Short and long presses differ.

2 · MODE

Looping-arrow key. Move through parameters; hold for reverse scroll where supported.

≪PF
3 · SHIFT / PF

Default function: move the selected digit during numeric editing.

4 · DOWN

Reduce a value or move down through choices.

5 · UP

Increase a value or move up through choices.

In the written procedures: LEVEL = first button (rectangle), MODE = second button (looped arrow), PF = third button (≪PF), followed by DOWN and UP. These graphical marks are reproduced as vector illustrations. When you change a value, press MODE once to store it (or wait at least three seconds). If a parameter does not appear, stop rather than guessing.

EVERYDAY OPERATION · HARDWARE-VERIFIED SELECTION

Select and run an existing programme

Once a programme is saved it does not need to be re-entered. d.prg selects the programme to EDIT; prg selects the programme to RUN. These are independent settings on our real Omron.

Three different displays: d.prg = 1 means edit stored Programme 1; prg = 1 means use Programme 1 for execution; pgsg reports the selected/executing programme and segment. The real controller changed from Programme 0 to Programme 1 on pgsg when prg changed, and prg = 1 survived a complete USB power cycle.
  1. 1
    With the external DC heater supply safely isolated, verify a plausible thermocouple temperature (PV) and the authorised controller and independent heater-safety configuration.
  2. 2
    From the normal PV/SP screen, press MODE briefly until r-r is displayed. Confirm rst. Do not equate a controller RESET with electrical isolation.
  3. 3
    While still in Operation Level, keep pressing MODE briefly until prg appears (typically after a-m and pgsg). Use UP/DOWN to select 1 for our saved 50 °C ramp-and-soak test, or the approved 0–7 slot for another experiment. Do not select the RUN programme at d.prg. The prg setting is normally editable only in RESET and when event inputs are not selecting the programme.
  4. 4
    Read back prg and pgsg. The monitor combines programme and segment, e.g. 1.00 means programme 1, segment 0. The programme digit changed to 1 in our real test; the precise segment suffix was not documented.
  5. 5
    To check a stored profile, from PV/SP press LEVEL briefly once to enter Programme Setting Level at d.prg. Select that programme for inspection, then use MODE to inspect s-no, d.seg, segment fields, pid, rpt and link without changing them. From Programme Setting Level, LEVEL briefly three times returns to Operation Level.
  6. 6
    Confirm r-r = rst, spmd = psp (programme mode), p-on = rst, rtsm = stop, correct PV and the approved programme-end action. Check the controller is not inadvertently in Manual mode.
  7. 7
    Commissioned systems only: when authorised to start, use MODE to reach r-r, select run using UP/DOWN, and verify the indication. Only then enable the separately approved heater supply path under the actual operating procedure. Do not use the MODE+DOWN shortcut until it has been independently checked.
  8. 8
    During a commissioned run, monitor actual PV versus programmed SP and the pgsg segment, prgt elapsed time and rptm repetitions. The ACTIVE LED shows demand, not measured current. To stop, use the authorised shutdown, command r-r = rst, disable the heater channel and isolate external DC. If eset = rst, the controller should return to RESET at the programme end, subject to actual electrical verification.
USB setup power limitation (Omron H185 §§2-4 and 5-23): the E58-CIFQ2 allows parameter editing and PV display, but the controller's control, alarm and auxiliary outputs will not operate without its specified terminal supply. USB-only operation has not yet been shown to advance the RUN programme timers. It cannot prove heater switching, safe output-off behaviour, or genuine PID temperature tracking.
VERIFIED EXAMPLE · ENTERED ON REAL E5CC-T

Create, save and select Programme 1: 50 °C at 2 °C/min, 15-minute soak

We entered this profile on the physical controller using the five keys, read back its settings after unplugging USB power, and confirmed the execution selection and RESET survived another USB restart. We have not commanded RUN or verified any heater output.

Button-by-button: create and store the profile

  1. 1
    Prepare and back up. Keep mains and heater DC supplies isolated; power only via the E58-CIFQ2 if using the setup bench. Verify the Type K thermocouple reads sensibly. Check r-r = rst. Record the prior contents of Programme 1 before overwriting that slot.
  2. 2
    Check configuration first: t-pr = pr (rate-of-rise method), pru = m (°C/min), t-u = h-m (hours.minutes), rtsm = stop, p-on = rst, eset = rst in Initial Setting Level; and spmd = psp in Adjustment Level. These are one-time settings — do not reset them unnecessarily.
  3. 3
    Start from the normal PV/SP display. Press LEVEL briefly once. When d.prg appears, use UP/DOWN to display 1. This selects the editing slot, not the RUN programme.
  4. 4
    Press MODE once for s-no. Use UP/DOWN to select 2 active segments, numbered 0 and 1.
  5. 5
    Press MODE once for d.seg. If it reads end, use UP/DOWN to select 0. end is the programme-wide settings position, not a third segment or a special END command.
  6. 6
    Press MODE for styp and set ramp. Press MODE for sp and set 50 °C. Press MODE for pr and set 2. With pru = m, that slope is 2 °C per minute.
  7. 7
    Press MODE once more after the ramp's last field (pr). On our real two-segment setup, the controller automatically displayed d.seg = 1. No separate manual increment was necessary.
  8. 8
    Press MODE for segment 1's styp; select soak. Press MODE for time; enter 0.15, meaning 15 minutes when t-u = h-m. A soak holds the preceding SP and does not have a separate sp or pr field.
  9. 9
    Press MODE after time. The real unit automatically advanced to d.seg = end. Press MODE to view programme-wide pid (we read 1); continue through any visible al-1, al-2, al-3 screens without altering unapproved alarm settings. Set rpt = 0 (no repeat), then link = end (no chaining).
  10. 10
    Save and verify. Normal front-panel editing has no separate Save programme button. Let the settings register, leave Programme Setting Level with three brief LEVEL presses, then return and read back the saved fields. We removed USB power until the display went dark, reconnected it, and found every programmed segment, rpt and link retained. Do not disconnect the controller during an active edit.
  11. 11
    Select the saved programme to RUN. Back in Operation Level, press MODE briefly until prg is displayed. We initially saw prg = 0 despite having edited d.prg = 1. Change prg to 1; the pgsg monitor then indicates Programme 1. We verified that prg = 1 and r-r = rst remained after a complete USB power cycle. Do not start RUN as part of this saving test.
If the current PV were 20 °C, the nominal commanded ramp would take (50 − 20) / 2 = 15 minutes, followed by 15 minutes soak. This is a setpoint trajectory, not proof that the heater or measured temperature can follow that rate. Conditional waits, controller limits, faults and temperature lag can affect actual results.
HARDWARE OBSERVATIONS · SCREEN MAP

Controller menus and PID settings we have actually read

Operation Level: with brief MODE presses, we observed a-m (Auto/Manual), pgsg (programme/segment monitor), prg (RUN selection), prgt = 0 (elapsed time), rptm = 0 (execution repetitions) and r-r = rst (RESET). Which additional screens appear depends on RUN, standby, hardware and parameter masking. At a-m, do not hold LEVEL: a long hold can switch to manual output control.

Programme Setting Level: d.prg → s-no → d.seg; for a rate-mode ramp: styp → sp → pr; for a soak: styp → time. After the last active segment, d.seg = end leads to pid → al-1 → al-2 → al-3 → rpt → link → d.prg. We saw alarm-value screens reading 0 on Programme 0, which does not prove the alarms are disabled.

PID Setting Level on our first unit: d.pid = 1 → 1.p = 8 → 1.i = 233 → 1.d = 40 → 1.olh = 100 → 1.oll = 0 → 1.aut = 1320 → d.pid. These are read-only observed values, not recommended tuning settings. 1.aut is an automatic PID selection-range limit, not the autotune command. 1.lba and mv-r were not displayed with our current configuration; never infer their actual values from a hidden screen.

USB setup power: Omron H185 §§2-4 and 5-23 explicitly allow keypad editing and PV display, but control, alarm and auxiliary outputs will not operate without the main controller supply. We have not established whether a USB-powered unit executes programme timing in RUN. This bench test cannot commission the SSR, real heater, fail-safe cutoff or live restart inhibition.

Expected result: the controller seeks to regulate at 80 °C, but the actual temperature rises gradually, depending on the load.

Every button press

  1. 1
    With the external DC heater supply isolated, start at the PV/SP display. Check one-time configuration is already approved (thermocouple type, °C, control mode, reset and restart behaviour).
  2. 2
    Press LEVEL briefly twice (less than one second each) to enter Adjustment Level. You should see the l.adj entry display.
  3. 3
    Press MODE repeatedly until spmd is displayed. Use ▲/▼ to select fsp (fixed setpoint mode). Press MODE to apply the setting.
  4. 4
    Continue pressing MODE until fsp (fixed setpoint value) appears. Use the SHIFT/PF key to select a digit where its default function is enabled, and ▲/▼ to enter 80.0 °C (or 80 when the commissioned input uses 1 °C resolution). Press MODE to store.
  5. 5
    Press LEVEL briefly twice to return to Operation Level. Confirm PV is plausible and the configured fixed setpoint is 80 °C. Read r-r via MODE and ensure it is rst until the authorised start.
  6. 6
    After commissioning checks, set r-r = run using ▲/▼, then press MODE to commit. Only then deliberately enable the heater power path according to the operator procedure. Watch PV move towards 80 °C; the exact heating rate is not controlled by this example.
  7. 7
    To stop, set r-r = rst, disengage the independent heater enable, isolate external DC power and allow the heater to cool. Confirm the output-off behaviour was validated during commissioning.

Prerequisites in Initial Setting: t-pr = pr, pru = m, t-u = h-m, eset = rst.

Every button press

  1. 1
    Keep the external heater PSU isolated. Start from PV/SP and confirm the one-time setup is complete: t-pr = pr, pru = m, t-u = h-m, rtsm = stop and the reviewed eset = rst. No need to re-enter these values for every run.
  2. 2
    Press LEVEL briefly twice to enter Adjustment Level (l.adj). Press MODE until spmd is shown. Choose psp (programme setpoint) using ▲/▼, then press MODE to store.
  3. 3
    Press LEVEL briefly twice to return to Operation Level. Press LEVEL briefly once to enter Program Setting Level, where d.prg is the programme selection. Set d.prg = 0 with ▲/▼ and press MODE.
  4. 4
    Continue pressing MODE to s-no (Number of Segments Used). Set 2 and press MODE to store. The ramp is segment 0, the timed soak is segment 1.
  5. 5
    Press MODE repeatedly until d.seg. Select segment 0 using ▲/▼, then press MODE to display the segment's settings. When styp appears, set ramp with ▲/▼, then press MODE.
  6. 6
    Within segment 0, press MODE until sp appears; enter 120.0 °C and press MODE. Move to pr; enter 2 and press MODE. Since pru = m, 2 means 2 °C/min, not 2 °C/hour.
  7. 7
    Press MODE until d.seg appears again. Choose segment 1 using ▲/▼; press MODE. Set styp = soak when this parameter appears, then press MODE.
  8. 8
    Continue with MODE to time for segment 1. Set 0.15, then press MODE to store it. With t-u = h-m, this is 0 hours, 15 minutes, not 0.15 hours. A soak segment needs no separate slope or target setpoint.
  9. 9
    While still in Program Setting Level, review each segment by selecting d.seg = 0 and 1 again. Check the programme's commissioned pid set and any alarms without changing their approved values.
  10. 10
    Press LEVEL briefly three times to return to Operation Level. Confirm r-r = rst before the start; check that spmd = psp, that the right programme is selected and that PV is plausible.
  11. 11
    After the independent protection and electrical checks are satisfied, set r-r = run using MODE, ▲/▼ and MODE to accept. Confirm the programme is running and SP begins its planned ramp. Only then deliberately enable the approved heater circuit.
  12. 12
    For a starting PV of 20 °C, the commanded SP takes roughly 50 minutes to reach 120 °C, followed by 15 minutes at that SP. With eset = rst, control stops at the end, subject to validated output-off behaviour. If you want continued control at 120 °C after 65 minutes, a qualified person may instead select eset = cont in Initial Setting Level; that means an indefinite final hold unless stopped separately.
End-of-program choice matters. eset = rst stops controller regulation after the 15-minute hold (subject to verified output-off behaviour). eset = cont continues holding 120 °C until a separate stop command. These are not equivalent.
ENGINEERING · ONE-TIME PER CONTROLLER

Initial configuration — do this before normal operation

These are the settings that made the original examples feel so long. They have not disappeared: they belong here, alongside commissioning and sign-off, rather than inside each temperature recipe.

Pre-commissioning instructions, not a completed safety approval. Apply separately to channel 1 and channel 2, with live heater power isolated. Do not assume a software reset or the SSR provides electrical isolation.

in-t, d-u, cntl

B · PROGRAMME UNITS

t-u, t-pr, pru

C · END & RESTART

rtsm, p-on, eset, mv-r

Full initial setup, button by button

  1. 1
    Record the hardware before changing anything: controller model, sensor type, controller output, independent heater supply and protection. Keep the external heater DC supply physically isolated. Record existing settings before overwriting them.
  2. 2
    From the normal PV/SP screen, hold LEVEL for at least 3 seconds to enter Initial Setting Level. The first parameter is normally in-t. In this setting level, heater regulation is stopped, but external power must still remain isolated.
  3. 3
    At in-t, use ▲/▼ to select 6 for the intended Type K input spanning −20.0…500.0 °C in 0.1 °C increments. For a different required span and resolution, confirm the correct Omron input type with the sensor specification first; 5 is −200…1300 °C in 1 °C increments. Press MODE to commit.
  4. 4
    Press MODE until d-u appears; choose c for Celsius, then press MODE. Continue to cntl; select pid only if this is the approved control method. Press MODE to save.
  5. 5
    Press MODE until t-u is shown. Select h-m (hours and minutes), press MODE. Find t-pr; choose pr (rate-of-rise programming), press MODE. Find pru; select m (per minute), press MODE. These settings apply to the worked ramp example.
  6. 6
    Find rtsm; set stop, so RESET stops controller regulation. Find p-on; set rst, so a new controller power-up enters RESET rather than restarting the programme. Press MODE after each change. These software settings do not replace the physical heater-enable restart interlock.
  7. 7
    Find eset (operation at programme end). For the 15-minute-hold-then-stop example, select rst, then press MODE. cont instead continues temperature control at the last setpoint indefinitely; use it only when your documented test method requires this.
  8. 8
    Hold LEVEL for at least 1 second to leave Initial Setting Level. From the normal Operation Level, press LEVEL twice briefly to enter Adjustment Level. Press MODE until spmd; set psp for programme operation (or fsp when carrying out the fixed setpoint example), then press MODE. Return to Operation Level with LEVEL twice briefly.
  9. 9
    With the heater disconnected, have the commissioning engineer confirm mv-r = 0.0% (MV at Reset), sensor-fault output behaviour, independent thermal protection and output-off state after control power is interrupted and restored. Advanced parameters may not be visible; do not override protections or guess. Check the Finder 13.61 relay returns to heater-disabled state after power restoration.
  10. 10
    Recheck the displayed settings against the table below and record them for each channel. Verify RUN/RESET and programme end on a safe inert load before use with an experimental heater. Both channels use E5CC-TQX3A5M-000; confirm the installed nameplates and validate any firmware-specific screen differences on each controller.

Once verified: ordinary experiments use the procedures above. Revisit these settings only if the hardware, safety case or intended programme behaviour changes. Record approved values, date and checks on the equipment's commissioning sheet.

Autotune · After the system has been commissioned

The E5CC-T PID autotune routine adjusts control constants by applying controlled output changes. It is not required for entering a temperature programme, but accurate rate tracking usually benefits from appropriate PID tuning.

  1. 1
    Carry out autotune only after the electrical system, sensor mounting, heater, load and independent temperature protections have been commissioned. Autotune deliberately cycles heater output and may cause overshoot.
  2. 2
    Use Fixed SP Mode for a representative operating target (for example 80 °C on a safe inert thermal load). Omron states that autotune during a programmed ramp may wait until ramp completion.
  3. 3
    Confirm cntl = pid, required PID set selected and the controller in run. Autotune is unavailable in some reset/mode conditions.
  4. 4
    From Operation Level, press LEVEL briefly twice to reach Adjustment Level. Press MODE repeatedly until at (AT Execute/Cancel) is displayed.
  5. 5
    Use ▲/▼ to select at-2 (100% autotune) and apply with Mode or 3-second pause. The TUNE indicator illuminates while AT runs.
  6. 6
    When autotune finishes, at returns to off and TUNE goes out. Record P/I/D values and verify temperature response before approving the tuned settings.
  7. 7
    To cancel AT, return to at and select off; do not assume partially completed tuning gives safe or appropriate constants.
Do not autotune a battery undergoing thermal runaway or another rapidly changing exothermic test. Use a stable, inert load and documented independent safety limits. Check the resulting controller response before use.

Reset and fault output checks

For the intended fail-safe design, both the software run/reset state and the physical heater enable interlock must be checked separately. The Omron supports a parameter called mv-r (MV at Reset), normally defaulting to 0.0% for the standard heating model, and an mv-e output on process-variable error. The values may be masked from the normal menus.

  1. Before live use, have the commissioning engineer confirm and document rtsm = stop, p-on = rst, and mv-r = 0.0%.
  2. Verify the programmed control output does not assert the SSR on reset, on power restoration or following a thermocouple fault. A controller parameter setting alone does not prove this.
  3. Confirm the independent Finder 13.61 enable circuit stays OFF after control-power restoration. Verify the behaviour on the actual hardware, not just the relay's general datasheet.

Omron H185 §§5-16-2 and 6-5: MV at Reset has precedence over MV at PV Error when in reset, and mv-r may be masked from the normal setting sequence. Do not change hidden advanced parameters without a documented commissioning plan.
