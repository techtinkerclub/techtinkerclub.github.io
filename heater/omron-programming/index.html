Programming the Omron E5CC-T

Button-by-button recipes for both programmable controller variants: E5CC-TQX3A5M-000 and -003
← Operator manual
Do not connect a live heater while learning controller keys. Changing a setpoint, entering RUN or changing programme settings may activate the control output. Use isolated controls or a safe commissioning setup. The exact availability of parameters also depends on protections, fitted controller options and previously configured settings.

Start here — which key is which?

O · LEVEL

Change menu levels. Short press vs long press matters.

M · MODE

Move to the next parameter in the current level.

S · SHIFT/PF

Move between digits if PF retains its default assignment.

▼ · DOWN

Decrease values; with MODE held for 1 s, RUN/RESET toggles.

▲ · UP

Increase values; hold to speed up changes.

Key names shown in the Omron H185 manual: O = Level, M = Mode, S = Shift/PF, U/D = Up/Down. The five key symbols on the actual E5CC-T front panel correspond to these functions. H185 official manual.

To enter a value: repeatedly press ▲/▼ or use PF/Shift to choose a digit, then ▲/▼ to edit it. Press MODE or wait at least 3 seconds to store the change. If the parameter is missing, the controller may be protected or in an incompatible operating mode; do not try undocumented overrides.

Example 1 · Heat to 80 °C and regulate there

This uses Fixed SP Mode (spmd = fsp), not a timed programme. Example assumes an inert, commissioned load with a correctly rated heater supply and an approved 80 °C operating target.

  1. 1
    Keep the external heater PSU and heater output isolated while entering parameters. Use the controller’s own display for checks.
  2. 2
    From the PV/SP display, hold Level (O) for at least 3 seconds. The controller enters Initial Setting Level; the first item is usually in-t. Control is stopped in this setting level.
  3. 3
    At in-t select 6 with ▲/▼ for a Type K sensor reading −20.0 to 500.0 °C. If your application requires the wider Type K range, the alternative 5 is −200 to 1300 °C with 1 °C display resolution. Use only the documented configuration.
  4. 4
    Press Mode (M) repeatedly to d-u; set c for Celsius. Continue to cntl and select pid if the approved controller mode is PID.
  5. 5
    In Initial Setting Level, locate rtsm and verify stop (reset stops control). Find p-on and specify rst for the proposed reset-on-power-up behaviour. This setting is not an independent heater interlock.
  6. 6
    Hold Level (O) for at least 1 second to return to Operation Level. From Operation, briefly press Level (O) once for Program Setting Level, then once again for Adjustment Level.
  7. 7
    In Adjustment Level press Mode (M) until the label spmd appears. Use ▲/▼ to select fsp (Fixed SP Mode).
  8. 8
    Press Mode (M) until fsp (Fixed Set Point) is displayed; enter 80.0 if input type 6 is used, or 80 with input type 5. The PF/Shift (S) key moves the active digit by default; ▲/▼ changes it.
  9. 9
    To save the displayed number, press Mode (M) or leave it unchanged for at least 3 seconds. Return to the normal PV/SP display by using Level until it reappears.
  10. 10
    Confirm the controller is in RUN when beginning an authorised functional test. From Operation Level, press Mode (M) repeatedly to r-r and set run, or use Mode + Down together for at least 1 second to toggle RUN/RESET. Verify the indicated state before permitting any heater demand.
  11. 11
    Only after approved commissioning: enable the required panel channel, then observe PV approaching 80.0 °C and the demand indicator. The controller seeks to regulate around the fixed target; it does not define a fixed ramp rate.

Fixed SP Mode is separate from the E5CC-T's multi-segment programme mode. The requested 80 °C is a setpoint; the time to reach it depends on the heater, load, PID tuning and maximum available power.

Use t-pr = pr (rate-of-rise programming), with pru = m and t-u = h-m. This uses two segments, starting from the current PV.

  1. 1
    With the heater DC circuit de-energised, start on the Omron PV/SP screen. Hold Level (O) ≥ 3 seconds to enter Initial Setting Level.
  2. 2
    Set/check in-t = 6 (Type K, 0.1 °C display over −20.0…500.0 °C). Select d-u = c, cntl = pid if that is the commissioned control mode.
  3. 3
    Press Mode (M) until t-u; select h-m. This means every segment duration such as 0.15 means 0 hours 15 minutes, not 0.15 hours.
  4. 4
    Continue through Initial Setting Level to t-pr; choose pr for the rate-of-rise programming method, not time (step-time mode).
  5. 5
    Find pru; select m (minutes). Segment slope is now in engineering units per minute; with the selected thermocouple and Celsius it means °C/min.
  6. 6
    Find rtsm; set stop. Find p-on; set rst to reset the programme after control-power restoration; test this behaviour as part of commissioning.
  7. 7
    Find eset; choose cont so the controller continues using the final setpoint once all segments finish. If you want heater control to stop instead of holding, the relevant option is rst.
  8. 8
    Hold Level (O) ≥ 1 second to return to Operation Level. Press Level (O) briefly twice to enter Adjustment Level; find spmd using Mode and set psp (programme setpoint).
  9. 9
    Return to Operation Level, then briefly press Level (O) once to enter Program Setting Level. Find d.prg; use ▲/▼ to choose 0 (programme 0).
  10. 10
    Use Mode to reach s-no (Number of Segments Used). Enter 2, because this recipe has one ramp segment and one timed soak.
  11. 11
    Use Mode to reach d.seg; select 0. Press Mode to reach the settings for segment 0, then find styp. Set ramp.
  12. 12
    For segment 0, find sp and set 120.0 °C (or 120 if 1 °C input resolution). Then find pr and set a ramp slope of 2.0 °C/min, matching the display resolution. There is no time value for this ramp segment: its duration follows from starting PV and slope.
  13. 13
    Return within Program Setting Level to d.seg and select 1. For segment 1 set styp = soak. Find time and set 0.15 (15 minutes, when t-u = h-m). No separate target SP or slope is needed for a soak segment.
  14. 14
    Use Mode to review pid (PID set number), retaining the previously commissioned set, commonly 1. Do not assign an arbitrary alarm value; use your approved temperature safety limits. Save each number with Mode or a 3-second pause.
  15. 15
    Return to the Operation screen and inspect selected programme number, segment count and values. To start after approved safety checks, find r-r and select run, or press Mode + Down together for at least 1 second to toggle RUN/RESET. Confirm RUN and the expected moving SP before enabling live heater power.
  16. 16
    The programme starts from the current measured PV when segment 0 is a ramp and reset operation is set to stop control. At an initial 20 °C, the commanded SP reaches 120 °C after approximately 50 minutes, then soaks for 15 minutes. With eset = cont, the controller continues at the final SP afterwards.
Important: the 2 °C/min figure is the setpoint slope. The actual measured temperature may climb more slowly. Entering 0.15 for segment 1 represents a 15-minute soak when the time unit is h-m. For a programme to stop heating automatically at the end instead of holding, review and validate eset = rst.

Autotune · After the system has been commissioned

The E5CC-T PID autotune routine adjusts control constants by applying controlled output changes. It is not required for entering a temperature programme, but accurate rate tracking usually benefits from appropriate PID tuning.

  1. 1
    Carry out autotune only after the electrical system, sensor mounting, heater, load and independent temperature protections have been commissioned. Autotune deliberately cycles heater output and may cause overshoot.
  2. 2
    Use Fixed SP Mode for a representative operating target (for example 80 °C on a safe inert thermal load). Omron states that autotune during a programmed ramp may wait until ramp completion.
  3. 3
    Confirm cntl = pid, required PID set selected and the controller in run. Autotune is unavailable in some reset/mode conditions.
  4. 4
    From Operation Level, press Level (O) briefly twice to reach Adjustment Level. Press Mode (M) repeatedly until at (AT Execute/Cancel) is displayed.
  5. 5
    Use ▲/▼ to select at-2 (100% autotune) and apply with Mode or 3-second pause. The TUNE indicator illuminates while AT runs.
  6. 6
    When autotune finishes, at returns to off and TUNE goes out. Record P/I/D values and verify temperature response before approving the tuned settings.
  7. 7
    To cancel AT, return to at and select off; do not assume partially completed tuning gives safe or appropriate constants.
Do not autotune a battery undergoing thermal runaway or another rapidly changing exothermic test. Use a stable, inert load and documented independent safety limits. Check the resulting controller response before use.
