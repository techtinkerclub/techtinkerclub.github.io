Set up a two-segment ramp-and-soak example or select a stored programme. The instructions update when you change the programme number, target, rate or hold time.

Before using a real controller: isolate the external heater supply and follow the approved equipment procedure. The controller must be in RESET before editing. This guide cannot read, verify or change hardware and does not authorise heater operation. The worked ramp example assumes Type K input 6 (−20.0 to 500.0 °C) with rate-of-rise programming.
