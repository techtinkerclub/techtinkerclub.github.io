This is a documentation review, not an electrical certification. Document control

The current electrical reference is R1.2 (14 drawings). D12 and D13 are superseded archives. An earlier stored R1.2 PDF export and a later clean PPTX/PDF source differ in editorial text on sheets 1, 6–9 and 14; this does not on its own establish that the PDF currently linked on GitHub differs from the linked PowerPoint. Verify the exact published files before reissuing a controlled PDF/PPTX pair. Existing slide metadata also contains an obsolete D7 design-review title/subject.

Do not change electrical nets, component values, connection order or commissioning status solely to improve presentation. Revise and approve the source document first; then export and visually check the PDF and update all website links under one document revision.
