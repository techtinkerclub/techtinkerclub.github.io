Channel 1 USB programme bench notes · 13 October 2026＋

Omron hardware validation status · 13 October 2026

Channel 1 controller: Type K PV responded correctly to warming by hand; Programme 1 (ramp 50 °C at 2 °C/min, soak 0.15, no repeat/link) was entered using the keys and survived a complete USB setup-power cycle. Changing Operation Level prg = 0 to prg = 1 changed the pgsg monitor to Programme 1; that selection survived another complete USB restart, with r-r = rst confirmed. A subsequent USB-only test confirmed that DOWN at r-r = rst changes the display to run (UP at RESET did not change it). The controller then showed prgt advancing and SV increasing: the internal programme clock and commanded ramp operate under USB setup power. The controller outputs themselves cannot operate from USB alone (Omron H185 §2-4 and Appendix A), and the ramp-to-soak transition, real heating, mains restoration, SSR demand and external heater safety have not been tested.

Omron H185 §§2-4 and 5-23 confirms that USB setup power supports PV display and parameter editing, but control and alarm outputs cannot operate without the rated controller terminal supply. The E5CC-T has OUT1/OUT2 control-output function indicators, not measurements of actual heater current; the larger E5EC-T/E5AC-T’s separate ramp/soak direction LEDs do not apply to this smaller model. This USB-only result does not validate heater operation or constitute commissioning.

USB-only programme execution trial & test method＋
OPTIONAL BENCH CHECK · NOT HEATER COMMISSIONING

USB-only programme execution — internal timer and ramp confirmed

The manufacturer confirms that the E58-CIFQ2 USB connection can display temperature and allow setting changes, but cannot operate the controller's control or auxiliary outputs. Physical testing now confirms r-r = run can be selected and the prgt timer advances while SV increases on the ramp. It has not established the end-of-ramp segment transition or end-of-programme behaviour. The following is a display-only hypothesis test, not a temperature-control or output test.

  1. 1
    Isolation prerequisite: verify there is no supply at the controller's normal AC power terminals, and that the external 0–60 V DC heater supply remains physically isolated. Do not connect controller mains during this USB test. Omron H185 also warns against switching normal controller supply ON/OFF while the USB cable is attached.
  2. 2
    With USB setup power only, confirm the thermocouple PV is plausible, prg = 1 and r-r = rst. Note pgsg, prgt and rptm before making a change.
  3. 3
    Only when this low-energy bench check has been authorised: from Operation Level r-r = rst, press DOWN briefly to request run. Physical result confirmed 13 October 2026: UP at RESET left rst unchanged, then DOWN selected run with E58-CIFQ2 USB setup power only. Do not connect or enable a heater, SSR power circuit or mains controller supply.
  4. 4
    The real controller accepted RUN on USB setup power; the next question is whether programme time advances. With r-r = run displayed, use brief MODE presses to find prgt. Physical PASS: its value changes over time and the SV increases. The clock and ramp calculation therefore work under USB-only setup power. Optionally inspect pgsg for the segment transition; do not change other settings. This validates displayed programme timing and increasing programmed setpoint only, not physical outputs or temperature tracking. If SV reaches the ramp target but the segment does not advance, configured wait/hold behaviour may be responsible when PV cannot reach SV on the unheated bench.
  5. 5
    Return to r-r = rst before unplugging USB, using UP if the actual menu permits and verifying the displayed change (the reverse direction is not yet physically checked). Confirm RESET; re-read prg = 1 after reconnection if needed. Record any unexpected message or failure to enter RUN. Do not interpret these checks as testing electrical output or PID performance.
Keep the two trials separate: USB-only checks are for display and stored settings. A later real functional test requires properly approved controller mains, output monitoring, independent protection and a safe inert load. No live-heater commissioning has been completed.
Observed Omron menus and PID values＋
HARDWARE OBSERVATIONS · SCREEN MAP

Controller menus and PID settings we have actually read

Operation Level: with brief MODE presses, the controller displayed a-m (Auto/Manual), pgsg (programme/segment monitor), prg (RUN selection), prgt = 0 (elapsed time), rptm = 0 (execution repetitions) and r-r = rst (RESET). Which additional screens appear depends on RUN, standby, hardware and parameter masking. At a-m, do not hold LEVEL: a long hold can switch to manual output control.

Programme Setting Level: d.prg → s-no → d.seg; for a rate-mode ramp: styp → sp → pr; for a soak: styp → time. After the last active segment, d.seg = end leads to pid → al-1 → al-2 → al-3 → rpt → link → d.prg. Alarm-value screens displayed reading 0 on Programme 0, which does not prove the alarms are disabled.

PID Setting Level on our first unit: d.pid = 1 → 1.p = 8 → 1.i = 233 → 1.d = 40 → 1.olh = 100 → 1.oll = 0 → 1.aut = 1320 → d.pid. These are read-only observed values, not recommended tuning settings. 1.aut is an automatic PID selection-range limit, not the autotune command. 1.lba and mv-r were not displayed with our current configuration; never infer their actual values from a hidden screen.

Front-panel indicators: Omron H185 §3-3-1 identifies OUT1/OUT2 as control-output function indicators on the E5CC-T; they are not measurements of actual heater current. No OUT indicator operation has been checked during the USB-only test. Separate ramp/soak direction indicators illustrated on larger E5EC-T/E5AC-T controllers are not provided on E5CC-T.

USB setup power: Omron H185 §§2-4 and 5-23 explicitly allow keypad editing and PV display, but control, alarm and auxiliary outputs will not operate without the main controller supply. With USB setup power alone, the real controller accepted run, showed prgt advancing over time and increased SV during Programme 1’s ramp. These internal-programme checks passed. They cannot commission the SSR, real heater, fail-safe cutoff or live restart inhibition.

Original complete pre-commissioning checklist＋

Checks required before first use

The controller must be inspected, tested and approved before its first powered heater test. Keep the completed commissioning record with the equipment.

  1. Confirm the part number of each fitted Finder 62.31 DIN socket and the physical coil/contact terminal layout.
  2. Demonstrate that the 24 V enable circuit returns to OFF after loss and restoration of control power, without being affected by the separate heater PSU cycling.
  3. Verify correct Omron sensor type, settings, programme, output mode and response to faulty thermocouple signals.
  4. Confirm breaker coordination, suitable enclosure earthing, cable sizing and the front connector ratings for the required DC current.
  5. Verify the Crydom SSR thermal rating, heat sinking and relevant protection.
  6. Confirm the Weidmüller output polarity, SSR drive current and the ACTIVE lamp's actual function.
  7. Confirm the emergency isolation arrangement and labelling, plus the behaviour following faults or interruptions.
  8. Check the final point-to-point wiring against the physical build, then record a signed electrical and functional inspection.
