# Tech Tinker Club website

This repository contains the public Tech Tinker Club website and its supporting club resources.

## Main areas

- Public club pages and navigation.
- Curriculum material for Years 4–6.
- Teacher notes and session-planning resources.
- Supporting tools and project applications used by the club.

The site is built with Jekyll and GitHub Pages.

## Repository structure

- `_pages/` — public site pages.
- `_curriculum/` — published curriculum content.
- `_teacher_notes/` — teacher notes; built with `noindex`.
- `assets/` — site images, styles and supporting assets.
- `docs/club/` — internal maintainer notes for club planning and authoring.

## Maintainer documentation

Start with [`docs/README.md`](docs/README.md).

The `docs/` and `scripts/` directories are excluded from the Jekyll site build so internal maintenance material is not published as website content.
