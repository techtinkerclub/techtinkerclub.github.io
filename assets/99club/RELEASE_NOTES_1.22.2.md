# 99 Club Studio v1.22.2 — Angles visual polish + Pie Chart variety

Release date: 11 September 2026

This release is intended to apply **directly over v1.21.3**. The withdrawn/internal v1.22 and v1.22.1 Angles packages are not prerequisites.

## Angles & Turns

- Adds the reliability-reviewed Angles Stage 1 module to Custom Worksheets: **104 active subtypes / 416 deterministic entries** across Y1–Y6.
- Holds back six unresolved research archetypes rather than shipping ambiguous geometry.
- Adds protected angle-diagram footprint space so page packing does not shrink geometry excessively.
- Reworks turn diagrams so START/END are attached to the actual rays; removes the detached colour-key caption.
- Increases label clearance on angle arcs and crowded line/point scenes.
- Enlarges triangle/shape drawing envelopes and uses more conservative label positions.
- Rebuilds the protractor with **1° minor ticks, 5° intermediate ticks, 10° major ticks and dual scales**.
- Protractor questions receive an extra protected print footprint.

## Pie Chart variety

- Expands Pie Charts from 4 to **16 deterministic visual variants per subtype**.
- The 37 pie-chart subtypes therefore expose **592 deterministic pool entries**.
- Adds 3–6-sector structural archetypes including balanced, dominant, equal-pair and long-tail distributions.
- Varies sector order, start rotation, colour offset, internal-label usage and bottom/right legend placement.
- Adds anti-repetition visual signatures so adjacent selected questions are less likely to use the same chart silhouette/layout.
- Uses dedicated integer-angle/friendly-percentage data banks for construction and angle-table tasks.

## Marking / working-space contract retained

- Visual estimation is explicit single-best-answer MCQ rather than undefined fuzzy-range marking.
- Genuine physical angle measurement/construction uses an explicit ±2° teacher tolerance.
- Explain/justify/show-working questions reserve framed pupil response space.
- Reasoning questions use explicit teacher rubrics with required mathematical criteria and accepted equivalents.

## Graph convention retained

- Bar/time/line graph y-axis titles remain vertically oriented and centred beside the left axis.

## Compatibility

The public 99 Club page, public Help, compact QR/recreation system, core `generator.js`, standard `pdf-layout.js`, `simple-pdf.js`, `qr-lite.js` and `99club.css` are unchanged from v1.21.3.
