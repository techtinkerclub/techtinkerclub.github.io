# 99 Club Studio v1.19

## Release focus

This release keeps the 11–99 workflow stable while giving post-99 challenges a controlled, extensible set of optional mental-maths extras. It also brings the comprehensive Help page visually into the same Studio design system.

## Post-99 extras

Optional extras are now offered only for Bronze–Diamond (and post-99 presets), never for the 11–99 progression. They are defined in a single registry so categories can be added or removed later without redesigning the editor.

Included groups: missing numbers/number properties, selected decimals/fractions/percentages, scaled facts/order of operations/angle facts, compact ratio work, concise measurement/time conversions and calculations, and mean. Comparison-heavy, graphical, area/perimeter and verbose problem-solving families are deliberately excluded from the 99 Club extras.

Bronze remains on its original mixed multiplication/division generator when no extras are selected. Selecting an extra temporarily uses a family mix with multiplication/division kept as fixed core; removing the final extra returns Bronze to its original mode.

## Help page

- Full Studio page width (matching the main app shell).
- Same button styling language as the main app.
- Comprehensive post-99 extras explanation and boundaries.
- The main Help & guide link opens in a new tab with `noopener`.
- The experimental Custom Worksheets route remains available at `/tools/99-club/custom/`, but is intentionally not linked from the public 99 Club interface or Help page yet. It is also excluded from the site search/sitemap while it remains a direct-URL beta.

## Compatibility

Built-in 11–99 and unchanged Bronze–Diamond presets retain their existing generation behaviour when no new extras are selected. Teacher notes, backups, recreation codes and the separate Custom Worksheets workspace are retained.
